# Voice & Telephony Providers for Cloudflare Agents

This directory provides integration guides and reference implementations for connecting the Cloudflare Agents SDK to leading realtime voice, speech recognition, and telephony platforms.

## Capabilities

- **Realtime Conversational Speech**: Build voice agents that converse naturally with users with sub-second response latency.
- **Inbound & Outbound Phone Calls**: Connect phone numbers directly to Cloudflare Agents using Twilio, Telnyx, or Plivo.
- **Speech-to-Text & Transcriptions**: Stream live audio for real-time transcription using Deepgram or AssemblyAI.
- **Natural Voice Synthesis**: Render conversational responses using ElevenLabs realistic neural voices.

## Supported Providers

- **[Deepgram](./doc/deepgram.md)**: Real-time speech-to-text via WebSocket audio streaming.
- **[ElevenLabs](./doc/elevenlabs.md)**: Conversational voice AI and expressive text-to-speech.
- **[AssemblyAI](./doc/assemblyai.md)**: Live streaming transcription and audio intelligence.
- **[Twilio](./doc/twilio.md)**: Two-way telephony audio streams via Twilio Media Streams.
- **[Telnyx](./doc/telnyx.md)**: Programmable voice calls and media streaming.
- **[Plivo](./doc/plivo.md)**: Programmable telephony integration for voice agents.

See [index.md](./index.md) for detailed provider specifications and links.
